Crie um aplicativo chamado "ME LEMBRA AI", focado em monitoramento de rotina, saúde e segurança para três perfis de usuários: idosos, adultos e crianças. 
O app deve funcionar como um assistente inteligente com foco em lembretes, monitoramento e comunicação familiar. 
FUNCIONALIDADES PRINCIPAIS: 
1.	PERFIS DE USUÁRIO: 
•	Idoso: 
Interface simplificada com letras grandes, botões visíveis e navegação intuitiva. 
Entrada de dados por voz. 
Alertas por voz (ex: "TOME O REMÉDIO", "VOCÊ TEM CONSULTA"). 
Botão de emergência (SOS). 
Detecção de palavra-chave ("SOCORRO"). 
Detecção de queda brusca. 
Compartilhamento de localização em tempo real. 
•	Adulto: 
Interface padrão. 
Lembretes inteligentes. 
Confirmação de compromissos. 
Integração com agenda. 
Notificações menos intrusivas. 
•	Criança: 
Gerenciado por responsáveis. 
Monitoramento de rotina (remédios, escola, atividades). 
Localização. 
Alertas para responsáveis. 
2.	SISTEMA DE LEMBRETES: 
•	Remédios 
•	Consultas 
•	Compromissos 
•	Lista de tarefas 
•	Lista de compras 
•	Eventos (aniversários, viagens, reuniões, etc.) 
•	Lembretes recorrentes (ex: tomar água) 
3.	ALERTAS INTELIGENTES: 
•	Notificação por voz 
•	Repetição caso não haja confirmação 
•	Escalonamento para familiares 
•	Registro de confirmação (ex: "remédio tomado") 
4.	SEGURANÇA: 
•	Botão SOS 
•	Ativação por voz ("SOCORRO") 
•	Detecção de queda 
•	Envio automático de: 
o 	Localização o 	Notificação para familiares 
5.	COMUNICAÇÃO: 
•	Chat (texto) 
•	Áudio 
•	Videochamada 
•	Comunicação entre familiar e usuário monitorado 
6.	MONITORAMENTO: 
•	Histórico de atividades 
•	Relatórios de adesão (remédios, compromissos) 
•	Notificação para familiares caso atividades não sejam realizadas 
7.	DIFERENCIAIS: 
•	Interface por voz 
•	Inteligência adaptativa (aprende rotina) 
•	UX acessível para idosos 
•	Central familiar integrada 
OBJETIVO: 
Criar um aplicativo simples, acessível e confiável que ajude famílias a cuidarem de idosos, adultos e crianças, garantindo segurança, organização e comunicação eficiente.
