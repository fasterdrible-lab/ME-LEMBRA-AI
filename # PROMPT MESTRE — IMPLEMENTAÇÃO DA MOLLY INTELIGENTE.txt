# PROMPT MESTRE — IMPLEMENTAÇÃO DA MOLLY INTELIGENTE

Você é um agente sênior de engenharia de software responsável por evoluir o aplicativo **ME-LEMBRA-AI**, repositório:

`https://github.com/fasterdrible-lab/ME-LEMBRA-AI.git`

O objetivo é transformar a **MOLLY** em uma assistente pessoal inteligente, conversacional e segura, especialmente adaptada para usuários 60+, sem comprometer as funcionalidades já existentes do aplicativo.

O projeto atual é desenvolvido em **Flutter/Dart**, utiliza **Firebase Auth, Firestore, Firebase Cloud Messaging, Firebase Storage, notificações locais, STT, TTS, GPS, acelerômetro, chat familiar e SOS**.

A nova arquitetura deve **reaproveitar ao máximo os serviços atuais**, evitando reescrever funções que já existem.

A MOLLY deverá ser capaz de:

* conversar naturalmente por voz e texto;
* compreender intenção;
* executar ações dentro do aplicativo;
* criar e consultar lembretes;
* interagir com familiares;
* consultar a rotina do usuário;
* possuir memória contextual;
* aprender preferências autorizadas;
* fornecer briefing diário;
* ativar funções por voz;
* possuir modo companhia;
* operar parcialmente offline;
* manter SOS e funções críticas independentes da IA;
* ser simples, amigável e segura para idosos.

# TAREFA 2 — CRIAR O NÚCLEO DA MOLLY

Criar:

`molly_agent_service.dart`

Esse serviço deve ser responsável por:

* receber entrada textual;
* receber transcrição de voz;
* preparar contexto;
* enviar mensagem ao modelo de IA;
* interpretar a resposta;
* identificar ferramentas;
* executar ferramentas autorizadas;
* retornar resposta final.

Fluxo:

```text
Usuário
   ↓
STT / Texto
   ↓
MollyAgentService
   ↓
Contexto
   ↓
Modelo IA
   ↓
Tool Calling
   ↓
Serviços internos do app
   ↓
Resposta
   ↓
TTS
```

O agente nunca deve acessar Firestore diretamente.

# TAREFA 4 — CLASSIFICAÇÃO DE RISCO

Criar três níveis:

```text
LOW
MEDIUM
CRITICAL
```

LOW:

* consultar lembretes;
* consultar horários;
* consultar perfil.

MEDIUM:

* criar lembrete;
* enviar mensagem;
* alterar lembrete.

CRITICAL:

* SOS;
* chamada telefônica;
* compartilhar localização;
* apagar dados sensíveis.

Regras:

LOW:
executar automaticamente.

MEDIUM:
confirmar quando houver ambiguidade.

CRITICAL:
sempre confirmar, exceto quando for um gatilho explícito de emergência já autorizado.

Exemplo:

> "Molly, liga para minha filha."

Resposta:

> "Você quer que eu ligue para Ana?"

# REGRA FINAL PARA O AGENTE DE DESENVOLVIMENTO

Execute uma tarefa por vez.

Após cada tarefa:

1. implementar;
2. analisar impacto;
3. executar testes;
4. corrigir erros;
5. verificar regressões;
6. atualizar documentação;
7. registrar no DEVLOG;
8. somente então iniciar a próxima tarefa.

Sempre priorize o funcionamento do aplicativo atual sobre qualquer nova funcionalidade da MOLLY.
